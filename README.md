# Field Notes: Multi-Page Blog Website

Project 03 (Beginner), The Sky Gen Web Development program.

**Author:** Laiba Irshad

**Live site:** https://laiba-irshad.github.io/field-notes/

## Pages
- `index.html` Home: hero, intro, links to the blog
- `blog.html` Blog: four post cards (image, title, date, preview)
- `contact.html` Contact: styled form and contact details

## Structure
```
index.html
blog.html
contact.html
css/style.css     (single shared stylesheet)
images/           (post illustrations)
screenshots/      (desktop and mobile PNGs for all three pages)
```
